## 🙋 이런 분께 맞아요

마음에 드는 사이트를 보면 **"이건 어떻게 만들었지?"** 궁금한데, 코드를 직접 뜯어볼 엄두는 안 나는 분께 맞아요. 클로드가 대신 뜯어보고, 따라 만들 수 있는 말로 정리해줘요.

- ✔ 우리 반·우리 모임 사이트를 만들고 싶은데 어디서부터 시작할지 막막한 분
- ✔ 잘 만든 사이트의 구성·디자인을 배우고 싶은 분
- ✔ 클로드 코드를 한 번쯤 써본 분

## 🧰 준비물 (한 번만)

1. **클로드 코드** (데스크톱 앱 또는 터미널)
2. **REA** (Reverse Engineer Anything) 스킬 설치 — 사이트가 실제로 배포한 파일을 근거로 분석해 주는 도구예요
3. **Node.js** — REA를 실행할 때 필요해요. 없으면 클로드가 설치를 도와줘요

> 💡 REA는 원래 앱을 분석하는 도구라서, 웹사이트를 분석하면 결과에 "electron" 같은 낯선 말이 섞여 나와요. 무시해도 괜찮아요.

## 🚀 사용법 (3단계)

1. 클로드 코드에 **분석할 사이트 주소**와 아래 [분석 프롬프트]를 입력해요
2. 클로드가 사이트 파일을 내려받고 REA로 분석한 뒤, **기술·디자인·콘텐츠·방문자 흐름**으로 정리해줘요
3. 정리된 결과를 보고 "**이걸 바탕으로 우리 ○○ 사이트 만들어줘**"라고 이어서 말해요

```prompt 분석 프롬프트
https://분석할-사이트.com 이 사이트 REA 활용해서 분석해줘.
구조·콘텐츠 전략·디자인 시스템·기술 스택·방문자 흐름을 따라 만들 수 있는 수준으로 정리해줘.
```

```prompt 만들기 프롬프트
이 분석 결과를 바탕으로, 우리 커뮤니티 챌린지 회차별 자료를 모으는 사이트를 만들어줘.
화면 구성과 사용 흐름은 비슷하게, 색·로고·문구는 우리 것으로 바꿔줘.
```

## 🔍 실제로 알게 된 것

| 살펴본 것 | 발견 |
|---|---|
| 기술 | 프레임워크 없이 HTML + 순수 JS. 작고 빠름 |
| 첫 화면 | 거대한 로고 하나에 인터랙션을 몰아줌 |
| 콘텐츠 | 실험마다 번호(EXP-001…)를 붙이고, 레시피 = 복사 프롬프트 + 지침 파일 + FAQ |
| 측정 | 쿠키 없는 자체 방문 기록으로 **"프롬프트 복사"를 핵심 지표**로 봄 |
| 흐름 | SNS 숏폼 → 레시피 페이지 → 운영자의 본업으로 연결 |

> 💡 REA는 결론마다 **관찰한 것 / 추론한 것 / 모르는 것**을 나눠서 알려줘요. "코드를 실행하지 않고 읽기만 했다"는 한계도 같이 읽어야 해요.

## ⚠️ 자주 묻는 질문

### 아무 사이트나 분석해도 돼요?

공개된 파일을 읽어서 배우는 건 괜찮지만, 결과물에 **다른 사이트의 로고·문구·이미지를 그대로 가져오면 안 돼요.** 구성과 흐름만 배우고, 브랜드 요소는 우리 것으로 바꿔요. 사이트의 robots.txt에 AI 활용 범위가 적혀 있으면 지켜요.

### 코딩을 몰라도 되나요?

네. 분석도, 만들기도 클로드가 해요. 나는 결과를 보고 "여기는 이렇게 바꿔줘"라고 말로 고치면 돼요.

### REA를 설치했는데 클로드가 못 찾아요

스킬만 설치하면 클로드 코드를 다시 시작하기 전까지 도구가 안 보일 수 있어요. 그래도 클로드가 터미널 명령(`npx rea-agents …`)으로 바로 실행할 수 있어요.
