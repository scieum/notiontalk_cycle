## 🎯 이번 주에 하는 것

1주차에는 영상마다 색, 글꼴, 속도가 조금씩 달라지고, 마음에 안 들어 다시 만드느라 토큰도 많이 들었죠. 이번 주에는 그 문제를 **하네스**로 묶어요.

**하네스 = 영상 만들 때마다 쓰는 기본 틀**이에요. 디자인, 모션, 작업 순서를 한 번 정해 두면 어떤 단원을 넣어도 **같은 디자인과 같은 모션**으로, **토큰을 낭비하지 않고** 영상이 나와요.

|  | 하네스 없이 | 하네스로 |
| --- | --- | --- |
| 디자인 | 영상마다 색, 글꼴, 글자 크기가 달라져요 | 항상 `design.md`, `video.md`대로 나와요 |
| 모션 | "부드럽게", "적당히"를 AI가 매번 다르게 해석해요 | `motion.md`의 숫자대로 같은 속도와 움직임이 나와요 |
| 토큰 | 다 만든 뒤 엎고, 같은 설명을 반복해요 | 장면표와 스냅보드를 먼저 승인하니까 엎는 일이 줄어요 |
| 수정 | 영상마다 같은 지적을 다시 해요 | 한 번 고친 건 규칙으로 남아요 |
| 다음 영상 | 처음부터 다시 설명해요 | "수업 영상 만들자"라고 하고 단원만 고르면 돼요 |

두 트랙 중 하나를 골라주세요.

## 🎬 B · 영상 한 편마다

준비(A)는 처음 한 번이에요. 다음 영상부터는 Code 탭에서 **A에서 만든 그 폴더**로 새 세션을 열고 "**수업 영상 만들자**" 한 줄로 시작해요. 승인 지점에서는 Claude가 멈추고 기다려요.

| 언제 | 이렇게 말해요 |
| --- | --- |
| 시작 | `수업 영상 만들자` |
| 브리프 답 | `한국사2 1910년대 묶음, 60초, 차시 끝 정리, 레퍼런스 없음` (모르면 `기본값`) |
| 승인 ① 교과서 정리 | `승인` 또는 `핵심 문장 3번 빼줘` |
| 승인 ② 장면표 | `A안` → `승인` |
| 승인 ③ 스냅보드 | `승인` 또는 `S4 숫자 더 크게` |
| 영상 뽑기 | `렌더링하자` |
| 마무리 | `이번에 고친 것 중 규칙으로 남길 것 제안해줘` |

> 💡 마무리 한 줄이 하네스를 키워요. 규칙으로 남긴 수정은 다음 영상에서 다시 말하지 않아도 돼요.

## ⚠️ 자주 묻는 질문

### 왜 교과서를 .md로 바꿔 두나요?

영상을 만들 때마다 PDF 전체를 다시 읽으면 시간과 토큰이 많이 들어요. 단원별 .md로 한 번 나눠 두면 그 단원 파일만 읽으면 돼요. 쪽수가 붙어 있어서 critic이 "교과서에 없는 내용"을 잡아낼 수도 있어요.

### 스캔본 PDF도 되나요?

글자가 이미지로 된 스캔본은 느리고 부정확할 수 있어요. 글자를 드래그해서 선택할 수 있는 PDF가 가장 잘 돼요. ②에서 "변환이 애매했던 곳"으로 알려 준 쪽만 직접 확인해요.

### 승인할 때 무엇을 봐야 해요?

- **교과서 정리**: 교과서 내용이 맞는지, 빠진 핵심 개념은 없는지 봐요. 여기서 틀리면 나중에 고치는 비용이 가장 커요.
- **장면표**: 장면마다 무엇이 움직여서 개념을 보여주는지 봐요.
- **스냅보드**: 글자가 뒷자리에서도 읽히는지, 색과 글꼴이 `design.md`대로인지 봐요.

### 카드만 나타났다 사라지는 PPT 같아요

장면표를 승인할 때 "이 장면은 무엇이 움직여서 개념을 보여주나?"를 물어보고, 도식 중심으로 다시 짜 달라고 해요. 예를 들어 "응결"이라는 글자 대신 수증기 입자가 느려지며 모여 물방울이 되는 장면이에요.
